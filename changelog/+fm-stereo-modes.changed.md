The FM stereo setting gained a third position: 自动 / 立体声 / 单声道. "立体声" pins the decoder to stereo by moving the blend thresholds to their stereo extremes, so a weak station no longer fades into mono; "自动" keeps the chip's factory blend and "单声道" is unchanged. The two property pairs the blend is built from run in opposite directions, so forcing stereo means RSSI/SNR 0 but multipath 100 — setting both to 0 would have forced mono.

Values saved by older builds mean something else now (1 used to be mono, it is stereo), so the setting moved to a new preferences key and the old value is translated once on upgrade instead of silently turning mono into stereo.
