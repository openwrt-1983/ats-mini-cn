The "充电单声道" (mono while charging) switch added in v2.45-2 is gone. It was a mitigation for the noise floor that charging raises, but it also changed how the station sounded as soon as the cable went in, and the user asked for it to be removed. The menu entry, its preferences key, the backup key, the debounce tick in the main loop and the stereo-indicator guard are all removed; the FM stereo setting is the only thing that decides between auto, stereo and mono again. A v2.45-2 backup that still carries settings.ChargeMono restores fine: unknown keys are counted as skipped, not as an error.
