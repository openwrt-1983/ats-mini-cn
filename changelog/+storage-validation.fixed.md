Damaged or foreign settings in NVS can no longer crash the receiver at power on: values that are used to look up bands, themes, time zones or modes are checked against the tables of the running firmware, and a band or a memory slot with an impossible frequency, band or modulation is ignored instead of being applied. The stored VFO slot number is range-checked the same way before it is used as an array index. Updating the firmware also keeps the tuned frequency, the SSB calibration and all stored memories instead of resetting them. The flash file system is formatted through the mount call, so the partition label is set before the format runs.
