BLE standby now behaves like a TV set in standby: the panel, the amplifier, Wi-Fi and the SI4732 itself are switched off (the tuner is powered down, which is the largest saving), the CPU runs at 80 MHz and the advertising interval is stretched so the radio duty cycle drops by an order of magnitude. Only the BLE radio keeps running, so the app can still connect and wake the unit; waking re-runs the cold start sequence and restores the previous band, frequency, bandwidth, AGC/AVC and DSP patch, at the cost of roughly 0.3 s. Periodic RSSI/RDS polling is skipped while the tuner is off so nothing talks to a sleeping chip.
