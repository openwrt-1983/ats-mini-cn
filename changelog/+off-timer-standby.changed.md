The off timer now ends in the long press standby instead of a shutdown that only a power cycle undoes: when the countdown runs out the receiver enters the same deep sleep as a long press, with the encoder button armed as the wake source, so holding the knob brings it back on the stored band and volume. The timer is spent when it fires, so a wake does not drop back into standby after the same interval in a later session. Boards where the encoder button doubles as BOOT keep the shutdown without a wake source, because holding it at reset enters the ROM download mode. Short pressing the Off Timer menu entry still shuts down without arming the button.
