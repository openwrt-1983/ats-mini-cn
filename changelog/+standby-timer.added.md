Settings gained "Standby timer", sitting just before "Off timer" and using the same 0-240 minute range. When it expires it enters Bluetooth standby (the TV style standby) instead of powering the unit off, so the receiver goes dark and quiet while the app can still wake it. It fires once, and it works even when another sleep mode is configured: a running CPU sleep is turned into standby on top of the dark panel instead of flashing the display.
